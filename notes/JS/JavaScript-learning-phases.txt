JAVASCRIPT – COMPLETE LEARNING BREAKDOWN (INTERVIEW ORIENTED)
=============================================================

--------------------------------------------------
LAYER 0 – JAVASCRIPT MENTAL MODEL (MOST IMPORTANT)
--------------------------------------------------

Before syntax, understand this:

JavaScript is:
- Single-threaded
- Event-driven
- Interpreted
- Runs inside a runtime (Browser / Node.js)

Core ideas:
- One call stack
- Non-blocking behavior via event loop
- Async handled through callbacks/promises

Interview focus:
Many interview questions indirectly test this model.

--------------------------------------------------
PHASE 1 – CORE LANGUAGE BASICS (FOUNDATION)
--------------------------------------------------

Topics:
- Variables: var, let, const
- Data types: primitive vs reference
- Operators
- Type coercion
- == vs ===
- Control flow: if, switch, loops

Key concepts:
- Hoisting
- Scope (global, function, block)

Interview focus:
- Difference between var, let, const
- Hoisting behavior

--------------------------------------------------
PHASE 2 – FUNCTIONS & SCOPE (VERY IMPORTANT)
--------------------------------------------------

JavaScript is function-heavy.

Topics:
- Function declaration vs function expression
- Arrow functions
- Scope & lexical environment
- Closures
- this keyword

Interview focus:
- Closure use cases
- this in normal vs arrow functions

--------------------------------------------------
PHASE 3 – OBJECTS & PROTOTYPES (CORE JS)
--------------------------------------------------

JavaScript uses prototype-based inheritance.

Topics:
- Objects & property access
- Prototypes
- Prototype chain
- __proto__ vs prototype
- Constructor functions
- class syntax (ES6 syntactic sugar)

Interview focus:
- How inheritance works in JS
- Prototype chain explanation

--------------------------------------------------
PHASE 4 – ASYNCHRONOUS JAVASCRIPT (MOST ASKED)
--------------------------------------------------

One of the most important interview areas.

Topics:
- Call stack
- Event loop
- Callback queue
- Promises
- .then(), .catch(), .finally()
- async / await

Interview focus:
- Execution order
- Promise chaining
- Error handling in async code

--------------------------------------------------
PHASE 5 – EXECUTION CONTEXT & MEMORY (ADVANCED CORE)
--------------------------------------------------

This explains HOW JS runs code internally.

Topics:
- Execution context
- Call stack
- Memory heap
- Garbage collection

Interview focus:
- Step-by-step code execution
- Memory leaks

Topics:

Interview focus:

- Fetch / Axios
