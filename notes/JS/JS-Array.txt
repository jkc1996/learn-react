JAVASCRIPT ARRAYS – THE COMPLETE GUIDE
===================================================

This note covers all essential array methods, categorized by usage.
It highlights the difference between "Mutating" (changing original)
and "Non-Mutating" (returning new) methods.

================================================
1. ITERATION & TRANSFORMATION (NON-MUTATING)
================================================

------------------------------------------------
1.1 .map()
------------------------------------------------
Usage: Transforms EVERY element in the array.
Returns: A NEW array of the same length.

const nums = [1, 2, 3];
const doubled = nums.map(num => num * 2);

console.log(doubled); // [2, 4, 6]

------------------------------------------------
1.2 .filter()
------------------------------------------------
Usage: Selects elements that pass a test.
Returns: A NEW array (can be smaller than original).

const nums = [10, 5, 20, 3];
const bigOnes = nums.filter(num => num > 5);

console.log(bigOnes); // [10, 20]

------------------------------------------------
1.3 .reduce()
------------------------------------------------
Usage: Reduces array to a SINGLE value (sum, object, etc.).

const nums = [10, 20, 30];
const sum = nums.reduce((acc, curr) => acc + curr, 0);

console.log(sum); // 60

================================================
2. SORTING & REORDERING (MUTATION VS IMMUTABLE)
================================================

------------------------------------------------
2.1 .sort() (MUTATING - CAREFUL!)
------------------------------------------------
Usage: Sorts the ORIGINAL array in place.
Default behavior: Sorts as STRINGS (Alphabetical).

// 1. String Sort (Default)
const fruits = ["Banana", "Apple", "Mango"];
fruits.sort();
console.log(fruits); // ["Apple", "Banana", "Mango"]

// 2. Numeric Sort (Ascending) - REQUIRES COMPARE FUNCTION
const numbers = [40, 100, 1, 5];
// numbers.sort(); -> INCORRECT: [1, 100, 40, 5] (String logic)
numbers.sort((a, b) => a - b);
console.log(numbers); // [1, 5, 40, 100]

// 3. Numeric Sort (Descending)
numbers.sort((a, b) => b - a);
console.log(numbers); // [100, 40, 5, 1]

// 4. Object Sort
const students = [{ name: "Alex", grade: 15 }, { name: "Dev", grade: 13 }];
students.sort((a, b) => a.grade - b.grade); // Sort by grade

// 5. International Sort
const items = ["réservé", "premier"];
items.sort((a, b) => a.localeCompare(b));

------------------------------------------------
2.2 .toSorted() (ES2023 - NON-MUTATING)
------------------------------------------------
Usage: Same as sort(), but returns a NEW array.
Original stays untouched.

const nums = [5, 1, 3];
const sorted = nums.toSorted((a, b) => a - b);

console.log(sorted); // [1, 3, 5]
console.log(nums);   // [5, 1, 3] (Safe!)

------------------------------------------------
2.3 .reverse() vs .toReversed()
------------------------------------------------
const arr = [1, 2, 3];

// Old (Mutates)
arr.reverse(); // arr is now [3, 2, 1]

// New ES2023 (Safe)
const newArr = arr.toReversed(); // Returns [1, 2, 3] (if reversed back)

================================================
3. SEARCHING & CHECKING
================================================

------------------------------------------------
3.1 .find()
------------------------------------------------
Usage: Returns the FIRST element that matches.
Returns: The value (or undefined).

const users = [{ id: 1, name: "A" }, { id: 2, name: "B" }];
const user = users.find(u => u.id === 2);

console.log(user); // { id: 2, name: "B" }

------------------------------------------------
3.2 .findIndex()
------------------------------------------------
Usage: Returns the INDEX of the first match.
Returns: Number (or -1 if not found).

const idx = users.findIndex(u => u.id === 2);
console.log(idx); // 1

------------------------------------------------
3.3 .some()
------------------------------------------------
Usage: Checks if AT LEAST ONE element passes.
Returns: Boolean (true/false).

const nums = [1, 3, 5, 8];
const hasEven = nums.some(n => n % 2 === 0);

console.log(hasEven); // true (because of 8)

------------------------------------------------
3.4 .every()
------------------------------------------------
Usage: Checks if ALL elements pass.
Returns: Boolean.

const nums = [2, 4, 6, 8];
const allEven = nums.every(n => n % 2 === 0);

console.log(allEven); // true

================================================
4. ADDING & REMOVING (SLICE vs SPLICE)
================================================

------------------------------------------------
4.1 .slice(start, end) (NON-MUTATING)
------------------------------------------------
Usage: Copies a section of the array.

const arr = ["a", "b", "c", "d"];
const part = arr.slice(1, 3);

console.log(part); // ["b", "c"]
console.log(arr);  // ["a", "b", "c", "d"] (Unchanged)

------------------------------------------------
4.2 .splice(start, count, items...) (MUTATING)
------------------------------------------------
Usage: Removes/Replaces items in place.

const arr = ["a", "b", "c", "d"];
arr.splice(1, 2, "X"); // Remove 2 items at index 1, add "X"

console.log(arr); // ["a", "X", "d"]

------------------------------------------------
4.3 .toSpliced() (ES2023 - NON-MUTATING)
------------------------------------------------
Usage: Safe version of splice.

const arr = ["a", "b", "c"];
const newArr = arr.toSpliced(1, 1, "X"); // Replace 'b' with 'X' inside new array

console.log(newArr); // ["a", "X", "c"]
console.log(arr);    // ["a", "b", "c"]

================================================
5. OTHER UTILITIES
================================================

------------------------------------------------
5.1 .flat(depth)
------------------------------------------------
Usage: Flattens nested arrays.

const arr = [1, [2, [3]]];
console.log(arr.flat(2)); // [1, 2, 3]

------------------------------------------------
.flatMap()

flatMap() is a built-in JavaScript array method that combines two operations into one efficient step:

Map: It runs a function on every element (just like .map()).

Flat: It flattens the result by one level (just like .flat(1)).

const sentences = ["Hello world", "How are you"];

const words = sentences
  .map(sentence => sentence.split(" ")) // [['Hello', 'world'], ['How', 'are', 'you']]
  .flat();                              // ['Hello', 'world', 'How', 'are', 'you']
-------------
A Powerful Trick: Adding and Removing Items(using flatmap)

Because flatMap flattens the result, you can use it to effectively filter and map at the same time.

Return an array [value] to keep an item.

Return an empty array [] to remove an item.

Return [val1, val2] to duplicate or add extra items.

const numbers = [1, -5, 2, -8, 3];

const processed = numbers.flatMap(num => {
  if (num < 0) return []; // Return empty array to remove
  return [num * 2];       // Return array with value to keep & transform
});

console.log(processed); 
// Output: [2, 4, 6] (Notice -5 and -8 are gone, others are doubled)

------------------------------------------------
5.2 .concat()
------------------------------------------------
Usage: Merges arrays.

const a = [1, 2];
const b = [3, 4];
console.log(a.concat(b)); // [1, 2, 3, 4]
// Note: Spread operator [...a, ...b] is more common now.

================================================
6. VALUE CHECKING & ACCESS (REQUESTED)
================================================

------------------------------------------------
6.1 .includes()
------------------------------------------------
Usage: Checks if an array contains a specific primitive value.
Returns: Boolean (true/false).
Note: Uses strict equality (===). It will NOT find an object 
unless it is the exact same reference.

const pets = ["cat", "dog", "bat"];

console.log(pets.includes("dog")); // true
console.log(pets.includes("rat")); // false

// Careful with objects!
const obj = { id: 1 };
const list = [obj];
console.log(list.includes({ id: 1 })); // false (Different reference)
console.log(list.includes(obj));       // true (Same reference)

------------------------------------------------
6.2 .at() (ES2022)
------------------------------------------------
Usage: Accesses an element at a specific index.
Key Feature: Supports NEGATIVE integers to count from the end.

const colors = ["red", "green", "blue"];

// The Old Way (for last item)
console.log(colors[colors.length - 1]); // "blue"

// The New Way
console.log(colors.at(-1)); // "blue"
console.log(colors.at(-2)); // "green"

================================================
7. BASIC STACK & QUEUE (MUTATING)
================================================
These are the most fundamental methods missing from 
the original list. All of these CHANGE the original array.

------------------------------------------------
7.1 .push() & .pop() (End of Array)
------------------------------------------------
push(...items): Adds to the END. Returns new length.
pop(): Removes from the END. Returns removed item.

const stack = [1, 2];
stack.push(3);    // [1, 2, 3]
const last = stack.pop(); // returns 3, stack is [1, 2]

------------------------------------------------
7.2 .unshift() & .shift() (Start of Array)
------------------------------------------------
unshift(...items): Adds to the START. Returns new length.
shift(): Removes from the START. Returns removed item.
Performance Note: These are slower than push/pop because 
all indexes must be re-calculated.

const queue = [1, 2];
queue.unshift(0); // [0, 1, 2]
const first = queue.shift(); // returns 0, queue is [1, 2]

================================================
8. CONVERSION & STATIC METHODS
================================================

------------------------------------------------
8.1 .join(separator)
------------------------------------------------
Usage: Joins all elements into a single string.
Default separator is a comma ",".

const words = ["I", "am", "learning"];
console.log(words.join(" ")); // "I am learning"
console.log(words.join("-")); // "I-am-learning"

------------------------------------------------
8.2 Array.from()
------------------------------------------------
Usage: Creates a new array from an "array-like" object 
(like a NodeList from DOM or a String) or generates sequences.

// 1. String to Array
console.log(Array.from("foo")); // ["f", "o", "o"]

// 2. Generating a sequence (0 to 4)
// The second argument is a map function
const range = Array.from({ length: 5 }, (_, i) => i);
console.log(range); // [0, 1, 2, 3, 4]

------------------------------------------------
8.3 Array.isArray()
------------------------------------------------
Usage: The ONLY safe way to check if a variable is an array.
typeof [] returns "object", so do not use typeof.

console.log(Array.isArray([1, 2])); // true
console.log(Array.isArray({}));     // false
console.log(Array.isArray(null));   // false

================================================
9. MODERN ALTERNATIVES (BEST PRACTICES)
================================================

------------------------------------------------
9.1 The Spread Operator (...) vs .concat()
------------------------------------------------
Most React/Modern JS developers prefer spread over concat.

const a = [1, 2];
const b = [3, 4];

// Old
const c = a.concat(b);

// Modern (Cleaner)
const d = [...a, ...b]; 

------------------------------------------------
9.2 Adding without Mutating (.push alternative)
------------------------------------------------
In React, you cannot use .push(). You must create a new array.

const oldArr = [1, 2];

// BAD (Mutates)
// oldArr.push(3); 

// GOOD (Returns new array)
const newArr = [...oldArr, 3];
